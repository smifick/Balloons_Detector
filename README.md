# Balloons Detector

Модуль находит жёлтые воздушные шарики в записанном видео и сохраняет MP4 с рамками и отметкой центра сопровождаемого шарика. Обе модели обучены на синтетических сценах. Готовые веса входят в репозиторий.

| Режим | Как работает | Веса |
| --- | --- | --- |
| `yolo` | Дообученный детектор YOLOv8n | [balloon-yolo.pt](vision/models/balloon-yolo.pt) |
| `opencv` (по умолчанию) | OpenCV выделяет области по цвету, SVM классифицирует их по форме и распределению яркости | [balloon-svm.xml](vision/models/balloon-svm.xml) |

## Быстрый запуск

Установите зависимости из корня репозитория. Команды рассчитаны на Python 3.12 и CPU-версию PyTorch.

```sh
python -m pip install torch==2.5.1 torchvision==0.20.1 --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r vision/requirements.txt
```

Запустите детектор на своём видео. Укажите новое имя выходного файла с расширением `.mp4`.

```sh
python -m vision.annotate input.mp4 output.mp4 --detector yolo
python -m vision.annotate input.mp4 output-opencv.mp4 --detector opencv
```

## Визуальное сопровождение

При появлении единственного шарика модуль начинает визуальное сопровождение. Во время краткого пропуска детекции (до 0,3 с) сохраняется состояние трека, чтобы продолжить сопровождение после повторного обнаружения. Центр рисуется только при подтверждённой детекции. После истечения интервала модуль может начать новое сопровождение. Выходное видео не содержит аудио.

## Результаты тестов

| Модель | Найдено шариков | Ложные срабатывания |
| --- | ---: | ---: |
| YOLOv8n | 72 / 72 | 0 на 360 отрицательных кадрах |
| OpenCV SVM | 72 / 72 | 0 на 360 отрицательных кадрах |

Также прошли четыре теста видеомодуля, включая обработку видео обеими моделями и сохранение трека при кратком пропуске.

Для повторной проверки выполните команды из корня репозитория.

```sh
python -m unittest discover -s tests -v
python -m vision.check
```

Проверка моделей использует отдельный seed и матрицу из трёх разрешений (320×240, 640×360, 1280×720) и четырёх условий (обычное освещение, темнота, блики и слабый контраст). В каждой комбинации по шесть кадров с шариком и 30 кадров без жёлтого шарика. Среди отрицательных примеров жёлтые диски, прямоугольники, кольца, красные шарики и пустой фон. Совпадение засчитывается при IoU ≥ 0,5, лишние рамки учитываются отдельно.

## Ограничения

- Результаты получены на синтетических кадрах. Точность на AR0234 и дальность 10 м остаются неподтверждёнными.
- Модуль обрабатывает видеофайлы. Подключение камеры, подвеса и лазера не реализовано.

## Обучение

```sh
python -m vision.train svm
python -m vision.train yolo --initial-weights yolov8n.pt
```

YOLOv8n дообучается в течение 24 эпох на 384 изображениях с отдельной выборкой из 96 изображений для валидации. Ultralytics загружает исходные веса, если локальный файл отсутствует. Генерируемые данные и журналы обучения сохраняются в `runs/`, веса — в `vision/models/`.
